# Priyansh Garg — Personal Academic Website

This repository contains the source code for my personal academic website hosted on [GitHub Pages](https://garg-priyansh.github.io).

## 📌 Features

* **Clean Academic Aesthetic**: Built using the LaTeX-inspired **Computer Modern** font family.
* **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.
* **Dynamic Publications**: Reads entries from `publications.json`. Automatically hides the Publications header and section if zero entries exist.
* **Lightweight**: Pure HTML5, CSS3, and vanilla JavaScript—no heavy dependencies.
